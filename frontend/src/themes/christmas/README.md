# Christmas Theme (Chủ Đề Giáng Sinh & Tuyết Rơi 3D)

Thư mục chứa các thành phần giao diện của Chủ đề Giáng Sinh dành cho Bảng xếp hạng tháng 12.

---

## Các thành phần dự kiến xây dựng:
1. `ChristmasHeaderBar.jsx`: Thanh header mùa lễ hội với Mũ Noel, Dây đèn Fairy lights, Vòng nguyệt quế.
2. `ChristmasDecorations.jsx`: Vector SVG trang trí Giáng Sinh sắc nét, siêu nhẹ.
3. `SnowfallEffect.jsx`: Hiệu ứng tuyết rơi 3D êm dịu, không giật lag.
4. `christmasTheme.css`: Styles viền tuyết phủ, ánh đèn lung linh, dải màu Crimson - Pine Green - Gold.
